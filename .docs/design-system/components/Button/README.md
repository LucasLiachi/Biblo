# Button

Classes em `bundle.css`, usadas em todo o app.

| Classe | Uso no app |
| :--- | :--- |
| `.btn-primary` | Confirmar diálogos, "Nova nota", "Manter a minha" |
| `.btn-secondary` | Ações de apoio ("Cancelar", "Novo diagrama", "Buscar nas bibliotecas") |
| `.btn-ghost` | Barras de ferramentas e ações discretas |
| `.btn-ai` | "Enviar" em Pergunte para o Biblo |
| `.btn-danger` | "Excluir" e "Parar" a resposta |
| `.btn-icon` | Botões só com ícone (sempre com `aria-label`) |
| `.kbd` | Atalho exibido no botão |

Texto sobre preenchimento de acento usa `--on-accent`. Foco visível com `:focus-visible` em `--focus-ring`.
