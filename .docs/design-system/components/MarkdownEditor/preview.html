Arquitetura de RAG Híbrido do Biblo

O motor de busca combina busca vetorial de cosseno HNSW via pgvector com busca textual clássica FTS em português. Veja o fluxo detalhado em [[fluxo-pedidos.excalidraw]] e as regras de negócio em [[regras-negocio.md]].

SELECT id, text, ts_rank(tsv, query) AS rank FROM chunks WHERE tsv @@ query ORDER BY rank DESC;
